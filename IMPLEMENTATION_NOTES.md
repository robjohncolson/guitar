# Two-beat repeater implementation

The user's simplified product replaces scale inference, lock, six-onset gating, four roles, density, and hole-filling. Those modules and tests were removed. The first accepted attack queues a single repeat of its detected Hz at `onset.t + 120 / bpm`; fractional MIDI preserves tuning. Notes are not quantized and occupancy never suppresses a repeat.

Direct BPM entry (40–240, default 100) starts the pulse when audio is enabled. Space tapping remains optional. BPM now persists alongside microphone/output preferences. A BPM change or Shift+Space clears queued/current repeats. M clears repeats without affecting click; Escape clears both while keeping the pulse. No pending echo survives muting and later unmuting.

`src/music/repeater.ts` owns the queue and self-mask. `src/audio/scheduler.ts` schedules repeats at their target time minus `outputLatency || baseLatency || 0`, with 75 ms lookahead and the existing 15 ms late tolerance. The 60 ms pitch-settling period does not add to the delay because events retain the original attack timestamp. Stalled-tab events are dropped rather than replayed in a burst.

The ear is unchanged: real local CREPE tiny, tfjs WebGL, official [1,1024] normalization and 360-bin postprocessing, AudioWorklet capture with 20 ms frame hops, and attack-based segmentation. The matching-pitch mask lasts for the repeat's duration plus 80 ms; speakers mode also uses AEC. A matching real guitar attack during that mask can be indistinguishable from speaker bleed. Headphones is the escape hatch. Physical guitar/speaker acceptance is still a human check.

Model source: `https://marl.github.io/crepe/model/model.json`, with the 13 `group*-shard1of1` paths relative to that directory (1,948,384 weight bytes). Tiny only. `npm run vendor:crepe` preserves the upstream model and licenses and records hashes. The build verifies every model asset. CREPE MIT license: `https://raw.githubusercontent.com/marl/crepe/master/LICENSE`; TensorFlow.js Apache license: `https://raw.githubusercontent.com/tensorflow/tfjs/master/LICENSE`.

Verification: 29 pure tests cover first-note repetition, exact detected pitch, off-grid timing, multiple attacks, two-beat delays across the BPM range, no repeated sustain, self-mask, latency, mute/panic clearing, tempo changes, stale events, settings migration, and the preserved capture/CREPE contract. The production build includes the model integrity check. The Chrome smoke test uses the real microphone worklet and model with a synthetic A2 pluck, compares oscillator pitch with the detected note, and verifies the audible start is one second after the attack at 120 BPM.

Human acceptance: open the live app in Chrome, enter 120 BPM, enable audio/mic, wait for CREPE ready, and pluck one string. Hear that pitch once a second later without any lock or training notes. Try several different notes, including between beats, then stop and ensure repeats stop. Set 80 BPM and expect 1.5 seconds; use M or Escape before a queued repeat and confirm it never sounds. Test laptop speakers for recursive feedback and H/headphones if needed.
